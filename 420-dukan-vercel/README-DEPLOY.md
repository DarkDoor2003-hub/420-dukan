## Deploy free on Vercel (from your phone browser)
1. Go to github.com, create a free account, create a new repository
   named `420-dukan`.
2. In the repository, choose "uploading an existing file" and upload all
   files from this folder (unzip first; do NOT upload `node_modules`).
3. Go to vercel.com, choose "Continue with GitHub", then
   Add New -> Project -> Import the `420-dukan` repository.
4. Vercel detects Vite automatically (settings are in `vercel.json`).
   Click Deploy.
5. You get a free address like https://420-dukan.vercel.app
   (if the name is taken, Vercel adds a suffix — whatever address it
   gives you, use that exact address everywhere).

## Alternative instant host (also free)
Drag the `dist` folder onto app.netlify.com/drop — the site goes live
immediately on a free address.
